# 技術書典 21「AIで本を書く」

技術書典 21 で頒布する『AIで本を書く』の原稿管理用リポジトリです。

Cursor、Git、GitHub、Re:VIEWを活用し、執筆「以外」の面倒な作業を減らして、技術同人誌を作る方法を紹介しています。

[技術書典 21](https://techbookfest.org/event/tbf21)は、2026 年 11 月 23 日（月・祝）に池袋サンシャインシティ 展示ホール D で開催されます。また、オンラインでは 11 月 21 日（土）から 12 月 6 日（日）まで開催されます。

[TechBooster の Re:VIEW 用の書籍テンプレート](https://github.com/TechBooster/ReVIEW-Template)を利用しています。

Re:VIEW Version 5.9 を使用しています。本のサイズは B5 です。

テンプレートとスタイルファイルのライセンスについては、各ファイルの権利表記および[テンプレートの権利に関する説明](https://github.com/TechBooster/ReVIEW-Template#権利)をご確認ください。
